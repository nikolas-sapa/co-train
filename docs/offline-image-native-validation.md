  Native training source, constructor digest and selected-source declarations
  remain unchanged.

## Limits

Configuration consistency is not authenticated provider/image availability or
layer attestation; the opt-in API is not wired into a live launch gate.
FakeRuntime tests do not prove installed framework compatibility or hardware
behavior. Static dispatch supports a narrow grammar, not hostile hooks, threads
or arbitrary framework classes. Protocol leaves compile only the pinned extracted
method, not full pytest hook routing or legacy179/full200 harness execution.
Metadata comparison remains SYNTHETIC-only, not live finder/cache custody.

No actual A/B child admission, image build/hydration, framework installation,
GPU update/save/fresh restore/update, real promoted reuse, paired BIRD or
co-training/cross-harness scientific evidence. Missing real scores stay unknown,
not zero. USD25 total gross all-charge containment and finite charged-end
termination remain unresolved external gates. No paid operation, retry campaign,
global setting change, default-provider fallback or ownership-marker cleanup.
Provider/paid/native/scientific authority remains closed.
