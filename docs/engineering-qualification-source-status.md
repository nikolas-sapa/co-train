# Qualification sources: status and execution boundaries

These files preserve source work, not permission to execute it. The public
checkpoint does not qualify a GPU run.

- `train/qualification_*.py`: blocked engineering candidates. The public isolated
  consumer still refuses parent-read custody. No admission gate was removed.
- `train/_qualification_directory_projection_spike.py` and
  `_qualification_mode_bit_spike.py`: rejected performance experiments.
- `train/_qualification_timer_certificate_spike.py`: accepted conditional pure
  arithmetic model only, not platform/native/process-containment evidence.
- `train/test_qualification_ac_volume.py`: exact four2GiB/full8GiB local test.
  It must not run from ordinary collection or reuse consumed local authority.
- Recovery helpers and their fixture records: source references only. Public
  identifying paths/metadata are replaced where noted. These derivatives are
  UNRUN and are not operational recovery recipes.
- `spec/spikes/reference/local-*`: historical local mechanism references.
  Sanitized derivatives are not byte-identical accepted artifacts. Original
  interpreter-hash allowances remain exhausted.
- `spec/spikes/{core-*,gpt-*,local-capability-candidate.py}`: historical author
  drafts, not the accepted reference bytes. In particular, the Core bulk-FD
  draft was rejected/unrun.
- `qualification_controls/v168-*`: isolated RPC loss/restoration mutations, not
  production import roots. Directory names do not establish acceptance.
- `spec/spikes/archive/native-metadata-query-source.py.txt`: consumed query's
  sanitized source reference, not an executable retry.
- `docs/qualification-history`: historical designs/reports. Old UNRUN/RED headers
  are historical states, not a substitute for current acceptance evidence.

The root `conftest.py` excludes 19 parent-only test modules plus the spike and
mutation-control trees before ordinary collection imports them. This does not
weaken production checks or replace the excluded tests with smaller fixtures.
Explicit paths, disabling conftest or another runner can bypass collection
policy. None grants fresh execution authority.

Budget/RPC/remote-verification tests and pure timer tests remain ordinary source
tests. Their presence is not a new run result. Historical suites were not rerun
for publication. See `docs/engineering-status-2026-11-09.md`.
