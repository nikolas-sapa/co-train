# Publication checks, before implementation

## Checks and numeric criteria

1. Parse every published Python source with Python3.12: zero syntax failures.
   Do not import project modules or execute historical tests.
2. Verify all ten canonical owner/consumer modules byte-for-byte against the
   recorded local originals, including the unchanged parent-read refusal gate.
   Verify copied shared contracts against integration originals.
3. Check the default collector's 19 parent-only exclusions, mutation-control
   directory and spike directory before import. A missing full-volume exclusion
   must fail the static check once; the complete list must pass.
4. Scan only listed first-party text: zero personal home paths, actual credential
   signatures or raw local receipt files. Synthetic derivatives are labeled
   UNRUN and cannot inherit the private originals' byte-level acceptance.
5. Match both sanitized recovery-helper identity constants against synthetic
   fixture records. One inode drift must fail the static check; matching records
   must pass. No internal workflow UUIDs may remain in published text.
6. Review the staged diff, file list and source hashes. Preserve the complete
   existing baseline tree without checking out assets. No protected WIP enters
   the commit.
7. Normal commit using the configured identity and hooks. Publish a review branch,
   then fast-forward GitHub main only as authorized. Both remote refs must equal
   the resulting commit. No force-push.

## Implementation

Publish canonical candidates, tests, local references, historical drafts and
current design/evidence notes. Keep private originals untouched. Add a root
pre-import collection exclusion for parent-only tests and reference/control
trees. Publish a source-integrity manifest and a stdlib-only verifier.

## Non-goals

No fresh correctness/performance acceptance of historical suites. No full-volume
read/write/recovery, interpreter hash, installed header/API read, compiler/build,
OS probe, SDK/provider/GPU operation, upload/install or scientific claim.
No model/data/wheel/lock acquisition or inspection. No deployment.
